# Сайт-визитка Екатерины Волковой

Статический одностраничный сайт: `index.html` + `styles.css` + `main.js` + `reviews.js` + `assets/img/`.
Сборка не нужна — содержимое папки можно залить на любой хостинг как есть.

## Посмотреть локально

```bash
python3 -m http.server 4321 --directory volkova-site
```

и открыть http://localhost:4321 (или просто открыть `index.html` в браузере).

## Что где менять

| Что | Где |
| --- | --- |
| Тексты, цены, услуги, образование | `index.html` — секции подписаны комментариями `<!-- ===== ... ===== -->` |
| Отзывы в карусели | `reviews.js` — по образцу внутри файла; пока список пуст, видны серые заглушки |
| Фото напротив «Моя задача…» | положить файл `assets/img/about.jpg` — он сам встанет вместо заглушки |
| Фото на первом экране | заменить `assets/img/hero.jpg` |
| Запись на приём в клинике | `index.html`, поиск по `df.clinic` |
| Онлайн-запись и чат для врачей | `index.html`, поиск по `t.me/dr_volkova_gyn` (текст сообщения — в `?text=` и `data-tg-text`) |
| Цвета и шрифты | `styles.css`, переменные в `:root` (`--wine` — цвет ФИО) |

## Перед публикацией

- Заполнить `reviews.js` и добавить `assets/img/about.jpg`.
- Когда будет домен, прописать полный адрес в `og:image` (иначе в мессенджерах не будет превью-картинки).
- `README.md` на хостинг загружать не нужно.
